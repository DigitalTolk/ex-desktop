# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| latest  | Yes       |
| older   | No        |

We support only the latest release. Please update before reporting a vulnerability.

## Reporting a vulnerability

**Do not open a public GitHub issue for security bugs.**

Email **security@digitaltolk.com** with:

- A description of the vulnerability and its impact
- Steps to reproduce or a proof-of-concept
- The version of ex Desktop you tested against

We will acknowledge your report within **3 business days** and aim to release a fix within **14 days** for critical issues.

We will credit you in the release notes unless you prefer to remain anonymous.
